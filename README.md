# 🛡️ Gemini 4 Neon Universal Cross-Project Verifier

A deep verification engine that enforces the **Universal Anti-Blind-Dumping Law**, native document payload extraction, and dual-audit discrepancy diffing using Google Gemini Web App in 4 Neon (Deeper Analysis) and Auto modes.

---

## 🧭 Core Mandate & Philosophy

In complex agentic workflows (Vedic astrology, competitive exam mathematics, software architecture, and high-stakes decisions), language models often hallucinate or smooth over critical contradictions.

The **Gemini 4 Neon Verifier** enforces:
1. **The Anti-Blind-Dumping Law:** Never output unverified answers without corroborating evidence, raw source data, and discrepancy diffing.
2. **Dual-Audit Discrepancy Diffing:** Symmetrically compares local calculations against Gemini 4 Neon deep reasoning to flag divergence.
3. **Automated Payload Extraction:** Converts PDFs, source code, images, and raw logs into full-fidelity text blocks for prompt injection.

---

## ⚙️ Model Dynamic Gearbox

- **🏎️ Gear 1 (Auto Mode):** Fast sanity checks, grammar/formatting fixes, and syntax verification.
- **🧠 Gear 2 (4 Neon Mode):** Deep reasoning, edge-case analysis, and complex mathematical/astrological cross-audits.

## 🚀 Installation & Usage

### 1. Installation in Antigravity / Agents
```bash
git clone https://github.com/Kanad590/gemini-neon-verifier.git ~/.gemini/config/skills/gemini-neon-verifier
```

### 2. Standalone Payload Staging
Extract and stage any complex file into a structured verification prompt:

```bash
python3 scripts/neon_payload_builder.py input_file.pdf "Verify calculation speed-traps and gazette cutoffs" staged_prompt.md
```
